NWarp is a modern HTTP server written in Rust - engineered to go beyond what Apache and Nginx offer, not just replicate it.

This is the default NWarp welcome page

If you can see this page, NWarp is successfully installed and serving requests. This page lives at www/index.html (or /var/www/nwarp-default/index.html if installed system-wide) and stays here until you replace it with your own site content.

What NWarp does today (Phase 1-3.5)

  • Serves static files (HTML, CSS, JS, images) over HTTP/1.1
  • HTTPS via TLSv1.3 (rustls), running alongside plain HTTP
  • Reverse proxy with round-robin load balancing (opt-in via proxy_route)
  • Active upstream health checks - dead upstreams are automatically skipped
  • Thread-pool concurrency, sized by worker_threads
  • Config-driven document root, host, and port
  • Access & error logging to file
  • Directory-traversal protection on every request path
  • Custom 404 / 403 / 405 / 500 / 502 / 503 error pages

Server configuration

Logs/var/log/nwarp/ or ./logs/
Service controlsystemctl {start|stop|restart|status} nwarp

Roadmap: built to go beyond Apache and Nginx

Phase 1-3.5 are done: static files, TLS/HTTPS, reverse proxy with load balancing, and active upstream health checks. Planned phases add reverse proxy and load balancing, HTTP/2 and HTTP/3, and a WASM module system for request handlers - a capability neither Apache nor Nginx offer natively. See docs/ARCHITECTURE.md for the complete roadmap.
